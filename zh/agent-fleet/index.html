FleetMux

哪个 agent 在等你，一眼看到，一键跳过去。

状态栏 ⬡ Claude 2 ●1 ◆ Codex 2 ●1：两个 Claude pane，一个在等审批；两个 Codex，一个已空闲。Ctrl-q Enter 跳到下一个需要你的 pane。

  • 按命令识别，不靠标题。Claude Code 把 pane 标题设成对话主题，Codex 设成任务名——真实服务器上 12 个 Claude、16 个 Codex，标题里只有 1 个写着 "claude"。看 pane_current_command 就没有歧义。
  • 状态从屏幕读。"esc to interrupt" = 忙；"Do you want to proceed?" = 等审批；都没有 = 空闲等你。29 个 pane 探测 0.4 秒。
  • 一条命令装好一切：tmux + 插件 + Starship + Nerd Font，可重复运行（CI 真装两遍做 diff），fleetmux-doctor 体检，fleetmux-start claude codex 直接拉起 agent。
# 安装
bash <(curl -fsSL https://raw.githubusercontent.com/xiaolongnk/fleetmux/main/bin/install.sh)
# 或者只要状态栏——加进你自己的 ~/.tmux.conf
set -g @plugin 'xiaolongnk/tmux-agent-status'
SuperHarness

只守一个数字：always-loaded tax。

CLAUDE.md 里的每一行，都是每次会话都要交的税。SuperHarness 把每一层——规则、skill、记忆、知识、任务状态——都拆成"每次都加载的小索引"和"命中才加载的库"。库可以无限长，索引必须持平。

  • 组合，不是单任务。需求进来 → registry 路由到项目 → 该项目的 agent 定义说"这里怎么干"，任务板说"干到哪了"。personal / work 两个 tier 决定 git 与 review 流程，不靠每次临场判断。
  • 教训进库，核心不涨。纠正 → learn 路由到对的层 → curate 把不再值得常驻的沉淀进 knowledge/ → check 证明索引没长。
  • 可证伪。superharness check 度量真实的加载面，税涨了就 exit 1；registry / agent / 任务板 / 记忆索引不一致也红。
npm create superharness my-hub
npx create-superharness add-project notes personal
npx create-superharness check
