Tools for people who run
a fleet of AI coding agents.

Built while running Claude Code, Codex, Cursor and Gemini across a real 40-project portfolio, every day. Each one solves a problem that only shows up past the fourth project or the fourth pane.

SH

SuperHarness

The harness that decides what agents work on: a project registry that routes requirements, layered disciplines, on-demand skills, a two-layer memory whose always-loaded core stays flat. npm create superharness

CLI · 13 skills · 15 disciplines · behavioral tests against a real agent
FM

FleetMux

The agent-native tmux distribution. One command installs tmux, plugins, Starship and a Nerd Font; the status bar counts your agent panes and marks the ones waiting for you; prefix+Enter jumps there.

macOS / Linux / WSL2 · idempotent installer · fleetmux-doctor
TA

tmux-agent-status

Just the status bar, as a TPM plugin for the tmux config you already have. set -g @plugin 'xiaolongnk/tmux-agent-status'

tmux ≥ 3.0 · bash · zero dependencies
TM

tmux-messager

Shell scripts for agents to send messages to each other across tmux panes — correct submit-key handling per CLI, pane discovery, automatic reply-to injection.

the wire between panes
TX

Termio

Watch your agents from your phone: pane output, messages, and a notification when one needs you. Uses the same probe as tmux-agent-status.

iOS · termio.xyz
